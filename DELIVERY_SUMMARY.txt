## 🚀 How to Start

### 1️⃣ Quick Setup
```bash
cd mathAI
npm run install-all
```

### 2️⃣ Start Development
```bash
npm run dev
```

### 3️⃣ Open Application
```
Frontend: http://localhost:3000
Backend:  http://localhost:5000
```

### 4️⃣ Explore Features
- Click "Launch Solver"
- Enter an equation
- See 3D visualization
- Export as PDF
